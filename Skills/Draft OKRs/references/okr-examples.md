

| Task-Based vs. Outcome-Oriented Objectives |  |  |
| ----- | ----- | ----- |
|  | **Bad Example** | **Good Example** |
| **Objective** | Update onboarding emails and launch a new nurture | Improve early-stage engagement by refreshing onboarding and lifecycle programs |
| **Why this is bad** | Task-based and activity-focused; does not describe an outcome | — |
| **Why this is good** | — | Outcome-oriented; clearly explains what change the work is intended to drive Success can be evaluated against a team-level goal |

| Vague vs. Measurable Results |  |  |
| ----- | ----- | ----- |
|  | **Bad Example** | **Good Example** |
| **Key Result** | Review current performance | Complete performance review and optimization plan by XDATE |
| **Why this is bad** | No deadline or definition of success | — |
| **Why this is good** | — | Time-bound and binary; progress and completion are unambiguous Clearly scorable and reviewable at quarter-end |

| Mixed Scope vs. Clean Roll-Up |  |  |
| ----- | ----- | ----- |
|  | **Bad Example** | **Good Example** |
| **Objective** | Improve onboarding, demand programs, and reporting | Improve onboarding lifecycle performance to support pipeline goals |
| **Why this is bad** | Spans multiple team goals; ownership and priority are unclear | — |
| **Why this is good** | — | Rolls up cleanly into a single team Objective Scope is focused and progress is easy to track |

| “Ongoing” Without Standards vs. With Standards |  |  |
| ----- | ----- | ----- |
|  | **Bad Example** | **Good Example** |
| **Key Result** | Support priority requests (ongoing) | Execute priority requests with 100% on-time delivery |
| **Why this is bad** | Lacks success criteria and cannot be scored | — |
| **Why this is good** | — | Defines a clear delivery standard Accountability and performance can be objectively assessed |
